# Portfolio Website

## Overview

Welcome to my portfolio website! This site showcases my journey, skills, and projects in web development. It serves as a space to present my work, experience, and aspirations to potential employers, collaborators, and clients. Here, you'll find a collection of projects, technical skills, and insights into my learning process and professional growth.

## Features

- **Dynamic Project Showcase**: Displays various web development projects, showcasing my skills in front-end and back-end development.
- **Responsive Design**: Optimized for all screen sizes, including desktops, tablets, and mobile devices.
- **Interactive Elements**: Hover effects on project cards for enhanced user experience.
- **Links to Source Code & Demos**: Direct links to GitHub repositories and live demos for each project.
- **Custom Styling**: Using Material UI components and custom CSS for a unique and modern look.

## Project Grid

The project grid dynamically displays different web development projects in a visually appealing format. Each card showcases:

- A preview image  
- Project title  
- Description  
- Featured tag (e.g., "Featured Project")  
- Links to GitHub repository and live demo  

**Styling & Responsiveness**:  
- The grid adjusts to different screen sizes, ensuring a smooth experience across all devices.  
- Hover effects provide a dynamic user experience.

---

## Responsive Design

The website is designed to be responsive across various devices:

- **Large Screens**:  
  Displays project grid with two columns.

- **Medium Screens (500px - 768px)**:  
  Adjusts to a single column for improved usability.

- **Small Screens (<500px)**:  
  Simplified layout for compact viewing while maintaining core functionality.
